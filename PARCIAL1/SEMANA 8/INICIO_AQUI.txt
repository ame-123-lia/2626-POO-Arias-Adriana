AL INICIAR:

    ==================================================
       EXPLICACIÓN DE PRINCIPIOS SOLID
    ==================================================

    🔹 S — RESPONSABILIDAD ÚNICA (Single Responsibility):
       Cada clase tiene UNA sola responsabilidad:
       • Producto/Bebida/Cliente: Guardan datos del dominio
       • Restaurante: Administra colecciones y validaciones
       • main.py: Interactúa con el usuario y delega al servicio

       ✓ Ventaja: Fácil de modificar, entender y mantener

    🔹 O — ABIERTO/CERRADO (Open/Closed):
       Abierto para extensión, cerrado para modificación.
       • Podemos crear nuevas subclases (ej: Platillo, Postre)
       • Restaurante NO necesita cambiar su código
       • Bebida extiende Producto automáticamente

       ✓ Ventaja: Agregar funciones sin romper código existente

    🔹 L — SUSTITUCIÓN DE LISKOV (Liskov Substitution):
       Bebida puede reemplazar a Producto sin romper el sistema.
       • Bebida hereda de Producto (relación válida)
       • Implementa el mismo método: mostrar_informacion()
       • Restaurante itera lista sin preguntar el tipo concreto
       • El polimorfismo funciona: cada objeto responde a su manera

       ✓ Ventaja: Código genérico que funciona con cualquier Producto

    ==================================================
    RESUMEN: Con SOLID, el código es flexible, mantenible y escalable 📈
    ==================================================

🎓 PRINCIPIOS SOLID DEMOSTRADOS
─────────────────────────────────────────────────────────────────────────────

S — Responsabilidad Única:
  ✓ Producto = datos
  ✓ Restaurante = administración
  ✓ main.py = interacción
  → Cambios localizados y seguros

O — Abierto/Cerrado:
  ✓ Bebida extiende Producto sin modificarlo
  ✓ Restaurante no se modifica
  ✓ Fácil agregar Platillo, Postre, etc.
  → Extensible sin riesgo

L — Sustitución de Liskov:
  ✓ Bebida es usable como Producto
  ✓ Polimorfismo funciona sin condicionales
  ✓ mostrar_informacion() respeta interfaz
  → Código elegante y genérico
