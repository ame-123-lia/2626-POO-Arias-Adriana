🔐 QUÉ GARANTIZA CADA PRINCIPIO
─────────────────────────────────────────────────────────────────────────────

SRP (Responsabilidad Única):
└─ Si necesitas cambiar la validación → editas solo Restaurante
└─ Si necesitas cambiar el formato del menú → editas solo main.py
└─ Si necesitas cambiar los datos de Producto → editas solo producto.py

OCP (Abierto/Cerrado):
└─ Quieres agregar Platillo? → Creates class Platillo(Producto)
└─ Restaurante NO cambia → acepta automaticamente la nueva clase
└─ Menos riesgo de romper código existente

LSP (Sustitución de Liskov):
└─ Bebida es Producto → funciona donde se espera Producto
└─ El método mostrar_informacion() respeta la interfaz
└─ Polimorfismo funciona sin condicionales "if isinstance"
